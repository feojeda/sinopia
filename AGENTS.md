# Reglas de Trabajo

1. **No modificar código de producción** sin autorización explícita del usuario
2. **Cada plan va en un branch** separado desde main
3. **Al finalizar un plan se crea un PR**, no se mergea directo
4. Los planes se documentan en `docs/PROPOSAL_*.md` antes de implementar
5. No implementar nada sin que el usuario apruebe el plan primero
