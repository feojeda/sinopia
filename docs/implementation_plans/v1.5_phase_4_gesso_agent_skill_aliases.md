## Capability Contract

`capability.json` should express a single capability:

```json
{
  "id": "gesso",
  "name": "Gesso / Lienzo en Blanco",
  "invocation": "/lienzo-en-blanco <nombre opcional>",
  "description": "Guide Phase 0 creative exploration and produce an approved Gesso for Sinopia.",
  "triggers": ["/lienzo-en-blanco", "/blank-canvas", "/tela-bianca", "/gesso", "/canva-blank-canvas"],
  "category": "sinopia"
}
```

The final shape may include fields required by existing adapter schema, but it must preserve the trigger list.

---

## Agent Instructions Contract

`instructions.md` must instruct the agent to:

- Run CLI preflight before creating or mutating Gesso state.
- Create a lienzo with `gsd-canva gesso create`.
- Offer methodology selection:
  - Socratic
  - Creative Brief
  - Jobs-to-be-Done
  - Design Thinking
  - 5W + 1H
- Guide the user conversationally, not as a rigid form.
- Record turns with `gesso append-turn`.
- Record structured notes with `gesso update-notes`.
- Present a final summary and layout proposal.
- Write the final approved Gesso through `gesso write`.
- Stop and require explicit user approval before `gesso confirm`.
- Never proceed to mockup before `gesso confirm`.
- After confirmation, offer transition to `/canva-mockup` or future `/boceto`.
- If creating a plan after Gesso, use `gesso link-plan` and still follow the existing mockup yield gate.

The instructions must also prohibit:

- Editing `lienzo.json` or `sesion.json` directly.
- Editing `decisions.json` directly.
- Autopopulating technical plan decisions without user consent.
- Creating Studi or Opere in this phase.

## Installer and Doctor Requirements

- `init --agent antigravity` installs the Gesso skill artifact if Antigravity skills are supported.
- `init --agent codex` installs the Gesso command artifact if Codex commands are supported.
- `init --agent opencode` installs the Gesso command artifact if OpenCode commands are supported.
- `init --agent all` includes Gesso in each supported adapter.
- `upgrade` treats Gesso as an official managed artifact.
- `--adopt` can adopt existing valid Gesso artifacts.
- `doctor --agent <agent>` reports Gesso validity along with existing capabilities.
- Existing `canva-*` artifacts remain installed and valid.
