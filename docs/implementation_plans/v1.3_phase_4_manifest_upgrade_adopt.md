---

## Goal

Make generated agent artifacts safe to manage over time through manifest v2, upgrade, adopt, and force-all semantics.

This phase turns adapter installation from "generate files" into a robust lifecycle with conflict handling and migration safety.

---

## Scope

Implement:

- Manifest v2 agent-adapter records.
- Migration path from manifest v1.
- `upgrade` regeneration for installed adapters.
- `--adopt` support for `.agents/skills`, `.codex/commands`, and `.opencode/commands`.
- `--force-all` safety rules for official adapter artifacts.
- Backups or conflict errors for locally modified managed files.

Do not introduce new agent adapters in this phase.

---

## Manifest v2 Shape

Target shape:

```json
{
  "schemaVersion": 2,
  "frameworkVersion": "x.y.z",
  "installedAt": "2026-05-30T00:00:00.000Z",
  "files": [],
  "agents": {
    "antigravity": {
      "adapter": "antigravity-skill-v1",
      "files": [
        {
          "source": "templates/agent-source/canva-mockup",
          "target": ".agents/skills/canva-mockup/SKILL.md",
          "sha256": "...",
          "managed": true
        }
      ]
    }
  }
}
```

Keep `files` for schema v1 compatibility until a later breaking release.

---

## Safety Rules

- Never delete `canva-plans/`.
- Never delete `delivery/`.
- Never delete `system_templates.json`.
- Never delete unmanaged files in `.agents/`, `.codex/`, `.opencode/`, or `.antigravity/`.
- `--force-all` may only overwrite official artifacts listed in the current manifest or official allowlist.
- If a managed file was locally modified, either create a backup before overwrite or fail with a conflict error.

---

## Tests

Add tests for:

- Manifest v1 migrates to v2.
- Fresh `init --agent antigravity` writes v2 agent records.
- `upgrade` regenerates managed Antigravity skill files.
- `upgrade` regenerates Codex/OpenCode files when installed.
- Locally modified managed file is protected.
- `--adopt` registers existing valid skill files.
- `--force-all` only touches official managed artifacts.
- Unmanaged files under `.agents/skills/` survive `upgrade` and `--force-all`.

Run:

```bash
npm test
```

---

## Acceptance Criteria

- Manifest accurately records adapter outputs.
- Upgrade is idempotent.
- Adopt can bring existing adapter artifacts under management.
- Force-all remains strictly scoped.
- Legacy manifest users are not broken.
