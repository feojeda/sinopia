## Goal

Make Antigravity 2.0 the primary supported agent interface by installing workspace skills under `.agents/skills/<id>/SKILL.md`.

This phase covers the project's main product objective: Spec-Driven Development for Canva inside Antigravity 2.0.

---

## Scope

Implement:

- `gsd-canva init --agent antigravity`
- `gsd-canva doctor --agent antigravity`
- Manifest tracking for generated Antigravity skill files.
- Safe preflight/conflict detection for `.agents/skills`.
- Tests for Antigravity skill installation and doctor validation.

Keep legacy `.antigravity/commands` available, but do not rely on it for Antigravity 2.0 support.

---

## Implementation Notes

Antigravity install target:

```text
.agents/skills/canva-mockup/SKILL.md
.agents/skills/canva-draft/SKILL.md
.agents/skills/canva-refine/SKILL.md
.agents/skills/canva-deliver/SKILL.md
```

Each skill must have frontmatter:

```yaml
---
name: canva-mockup
description: Use when the user invokes /canva-mockup or asks to create a Canva mockup with the gsd-canva lifecycle.
---
```

`doctor --agent antigravity` must validate:

- `.agents/skills/` exists or can be created.
- Each official skill has `SKILL.md`.
- Each `SKILL.md` has frontmatter.
- `name` and `description` are present.

If `.antigravity/commands/` exists without `.agents/skills/`, `doctor` should warn that the workspace appears to use legacy Antigravity commands.

---

## Tests

Add tests for:

- `init --agent antigravity` creates all four skill files.
- Generated skill files contain required frontmatter.
- Manifest records generated skill files.
- `doctor --agent antigravity` passes for valid skills.
- `doctor --agent antigravity` fails when a required `SKILL.md` is missing.
- `doctor --agent antigravity` fails when frontmatter is invalid.
- Legacy `.antigravity/commands/` alone triggers warning or failure according to final CLI contract.

Run:

```bash
npm test
```

---

## Acceptance Criteria

- Antigravity 2.0 no longer depends on `.antigravity/commands/`.
- Generated skills are discoverable in the expected `.agents/skills/<id>/SKILL.md` structure.
- Current legacy users are not broken.
- `doctor --agent antigravity` validates the Antigravity 2.0 surface, not only legacy directories.
