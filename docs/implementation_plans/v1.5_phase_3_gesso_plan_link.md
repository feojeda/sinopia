## Goal

Connect an approved Gesso to the existing mockup plan lifecycle without changing the existing `decisions.json` yield gate.

Gesso becomes contextual input for Abbozzo/mockup, but it does not replace technical decisions or automatically approve them.

---

```text
docs/implementation_plans/v1.5_execution_review_protocol.md
```

---

## Scope

Implement:

- `gsd-canva gesso link-plan --id <LIENZO_ID> --plan <PLAN_ID> [--json]`
- `sourceLienzoId` optional field in `plan.json`.
- `linkedPlanId` in `lienzo.json`.
- State transition from `gesso:gesso_listo` to `gesso:con_mockup`.
- Hash verification before linking.
- Status/list output showing linked plan when present.

Do not implement yet:

- Agent skill changes.
- Automatic plan creation from Gesso.
- Autopopulation of `decisions.json`.
- Any changes to the mockup state machine beyond optional metadata.

---

## Link Contract

Preconditions:

- Lienzo exists.
- Lienzo status is `gesso_listo`.
- `gesso.md` verifies against `confirmation.gessoHash`.
- Plan exists in `canva-plans/`.
- Plan is not delivered/closed in a way that makes linking misleading.

On success:

- `lienzo.json.linkedPlanId = "<PLAN_ID>"`
- `lienzo.json.status = "con_mockup"`
- `lienzo.json.timestamps.updated` changes.
- `lienzo.json.history` records `link-plan`.
- `plan.json.sourceLienzoId = "<LIENZO_ID>"`
- `plan.json.history` records `linked-gesso` or equivalent.

Do not alter:

- `decisions.json`
- `plan.phase`
- `plan.status`
- existing confirmation hash in `decisions.json`

---

## Validation Rules

- Linking an `en_blanco` lienzo fails.
- Linking a lienzo with changed `gesso.md` fails.
- Linking to a missing plan fails.
- Linking the same lienzo to the same plan should be idempotent or return a clear already-linked result.
- Linking a lienzo already linked to another plan should fail unless a future explicit relink command is designed.
- Linking a plan already linked to another lienzo should fail.

---

## Errors

Use:

- `GSDC_GESSO_NOT_FOUND` exit 31
- `GSDC_GESSO_INVALID_STATE` exit 32
- `GSDC_GESSO_CHANGED_AFTER_CONFIRMATION` exit 35
- `GSDC_GESSO_LINK_FAILED` exit 36

Use existing plan-not-found behavior for missing plan only if already standardized; otherwise wrap details under `GSDC_GESSO_LINK_FAILED`.

---

## Tests

Required tests:

- Approved Gesso links to an existing plan.
- Link writes `linkedPlanId` to `lienzo.json`.
- Link writes `sourceLienzoId` to `plan.json`.
- Link does not modify `decisions.json`.
- Link does not transition plan phase/status.
- Link rejects `en_blanco` lienzo.
- Link rejects tampered `gesso.md`.
- Link rejects missing plan.
- Link rejects linking to a second different plan.
- Link rejects linking a plan already linked to a different lienzo.
- Existing `/canva-mockup` direct flow still works without `sourceLienzoId`.
- Existing plan tests still pass.

Run:

```bash
npm test
```

---

## Acceptance Criteria

- Approved Gesso can be traced to a mockup plan.
- Mockup plan lifecycle stays compatible.
- No automatic technical decisions are written from Gesso.
- `npm test` passes.
