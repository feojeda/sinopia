## Goal

Expose structured interactive-question state through the CLI and allow agents to save one field answer at a time without writing `decisions.json` directly.

---

## Scope

Implement:

- `planManager.questions(planId)`.
- `planManager.answer(planId, field, value)`.
- CLI commands:
  - `gsd-canva plan questions --id <ID> [--json]`
  - `gsd-canva plan answer --id <ID> --field <campo> --value <valor> [--json]`
- Human and JSON output for both commands.
- `try/finally` lock release for `questions()` and `answer()`.
- Choice validation:
  - numeric pure values rejected with `reason: "numeric_value"`.
  - canonical option matching.
  - custom values accepted only when `allowCustom === true`.
  - placeholders rejected with `reason: "placeholder_value"`.
- Optional answer semantics:
  - `optionalAnswered[field] = true` for empty and non-empty optional answers.
  - required fields never trust `optionalAnswered`.

Do not implement yet:

- `reset-confirmation`.
- Agent-source instruction changes.
- Confirmation parsing changes in agent instructions.

---

## questions() Contract

Return structured state including:

- `planId`
- `phase`
- `status`
- `readOnly`
- `confirmed`
- `totalFields`
- `filledCount`
- `requiredPendingCount`
- `optionalPendingCount`
- `requiredFieldsComplete`
- `allQuestionsAddressed`
- `optionalAnsweredStatus`
- `suggestedAction`
- `editable`
- `filled`
- `pending`

`questions()` must not throw `GSDC_INVALID_STATE`; it should return read-only diagnostics for non-editable states.

---

## Tests

Add tests for:

- Empty plan returns six required pending and one optional pending.
- Partial answers produce correct `filled` and `pending`.
- Required complete plus unasked assets gives `requiredFieldsComplete: true` and `allQuestionsAddressed: false`.
- Empty assets marks `optionalAnsweredStatus.assets: true`.
- Non-empty assets also marks `optionalAnsweredStatus.assets: true`.
- Confirmed or later states return read-only.
- `questions()` releases lock on parse/read errors.
- Invalid field exits with the selected field error code.
- Wrong state exits with `GSDC_INVALID_STATE`.
- Confirmed decisions exit with locked-decisions error.
- Numeric choice values are rejected.
- Custom choice values are accepted when allowed.
- A dummy `allowCustom: false` choice validation path rejects unlisted values.
- Placeholder exact values are rejected.
- `"TODO: definir colores"` is not treated as an exact placeholder.
- `plan questions --json` and `plan answer --json` are not double-wrapped.

Run:

```bash
npm test
```

## Acceptance Criteria

- Agents can inspect pending fields through CLI JSON.
- Agents can save answers atomically through CLI.
- No direct `decisions.json` write is needed for question answering.
- Lock release is covered.
- Existing lifecycle tests still pass.
