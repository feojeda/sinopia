## Goal

Create the neutral agent-capability source model and pure adapter-rendering infrastructure without changing current install behavior.

This phase must be behavior-preserving for existing users.

---

## Implementation Notes

Move operational command content into neutral `instructions.md` files by copying, not deleting, current `templates/commands/*.md`.

Each `capability.json` must include:

```json
{
  "id": "canva-mockup",
  "title": "Canva Mockup",
  "invocation": "/canva-mockup <nombre_diseño>",
  "description": "Create the mockup phase using the gsd-canva lifecycle.",
  "triggers": ["/canva-mockup"],
  "category": "gsd-canva",
  "supportedAgents": ["antigravity", "codex", "opencode"]
}
```

Renderer functions must be pure: inputs are capability metadata and instruction markdown; output is a string plus target path metadata. They must not write files.

## Tests

Add focused unit tests for:

- Loading all four capabilities.
- Rejecting missing `id`.
- Rejecting missing `description`.
- Rejecting empty `instructions.md`.
- `renderAntigravitySkill()` emits YAML frontmatter with `name` and `description`.
- `renderCodexCommand()` emits a markdown slash command header.
- `renderOpenCodeCommand()` emits description frontmatter.

Run:

```bash
npm test
```
