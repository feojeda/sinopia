## Goal

Close v1.4 by documenting the interactive question workflow, validating end-to-end behavior, and removing inconsistencies between docs, CLI help, agent-source instructions, and tests.

## Scope

Update:

- `README.md`
- Active implementation docs if needed.
- Error catalog documentation.
- CLI help text if new commands/options are unclear.
- Any tests needed to prove end-to-end flow.

Verify:

- `gsd-canva plan questions`
- `gsd-canva plan answer`

- `confirm-decisions`
- `resolve-questions`
- `submit-mockup`
- rendered adapter artifacts after `init --agent all`

## Documentation Requirements

Document:

- How `/canva-mockup` gathers structured answers.
- Required vs optional fields.
- How users decline optional assets.
- How final confirmation works.
- How to reset confirmation.
- That agents should not edit `decisions.json` directly.
- That Antigravity 2.0 uses `.agents/skills`.
- That `.antigravity/commands/` remains legacy/deprecated compatibility.
- Whether the phase chose error-code Option A or Option B from Phase 1.

Create or extend tests for one full flow:

1. `plan create`.

3. Multiple `plan answer` calls.
4. Optional assets declined or provided.
5. `confirm-decisions`.
6. `resolve-questions`.
7. stale/reset path.
8. re-answer optional field.
9. re-confirm.
10. `submit-mockup`.

Also verify generated adapter output:

```bash

```

Use temporary directories in tests; do not mutate the repository root.
