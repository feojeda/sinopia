# v1.3 Phase 3: Codex and OpenCode Adapters

**Proposal**: `docs/PROPOSAL_v1.3_agent_adapters.md`  
**Depends on**: Phase 1 and Phase 2  
**Branch**: `codex/v1.3-codex-opencode-adapters`  
**Base branch**: default branch after Phase 2 merges  
**PR target**: default branch  
**Status**: Pending approval

---

## Goal

Add portable agent-interface support for Codex and OpenCode using the adapter architecture from Phase 1.

Antigravity remains the primary target. OpenCode support may be marked experimental until its command format is verified.

---

## Scope

Implement:

- `gsd-canva init --agent codex`
- `gsd-canva init --agent opencode`
- `gsd-canva init --agent all`
- `gsd-canva doctor --agent codex`
- `gsd-canva doctor --agent opencode`
- `gsd-canva doctor --agent all`
- Manifest tracking for Codex and OpenCode generated files.
- Tests for Codex/OpenCode installation and doctor checks.

Do not change Antigravity behavior from Phase 2 except for shared adapter plumbing.

---

## Tests

Add tests for:

- `init --agent codex` creates all Codex command files.
- `init --agent opencode` creates all OpenCode command files.
- `init --agent all` creates Antigravity, Codex, and OpenCode artifacts.
- `doctor --agent codex` validates expected command files.
- `doctor --agent opencode` validates expected command files.
- `doctor --agent all` validates all installed adapters.
- Manifest records files under the correct agent adapter.

Run:

```bash
npm test
```

---

## Acceptance Criteria

- Codex artifacts are generated from the same neutral capability source.
- OpenCode artifacts are generated from the same neutral capability source.
- `--agent all` works without overwriting unmanaged files.
- Antigravity skill support remains intact.
